📱 Mit Handy-Kamera scannen → App öffnet sich

So bekommen Mitarbeiter die App aufs Handy:
1. QR-Code mit der Kamera scannen
2. Link tippen → App öffnet sich im Browser
3. iPhone: Teilen-Knopf → „Zum Home-Bildschirm"
    Android: Menü (⋮) → „Zum Startbildschirm hinzufügen"
4. Symbol auf dem Home-Screen drücken — fertig.

Wichtig: Beim ersten Start einmal Kamera erlauben.
